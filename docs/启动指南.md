## 1. 关于 conda：`(base)` 是什么、`conda activate` 为什么之前没反应

### 1.1 `conda init powershell` 做了什么（一次性操作）

在 PowerShell 配置文件中（`C:\Users\ASUS\Documents\PowerShell\profile.ps1`）写入了一段初始化代码。效果：

- **每次打开新的 PowerShell 窗口**，自动加载 conda 的 shell 函数（`conda activate` 才能真正生效）；
- conda 默认**自动激活 base 环境**，所以你的提示符前出现了 `(base)`——这是正常现象，说明 conda 已初始化成功。

### 1.2 之前的"没反应"

之前 PowerShell 里没有这段初始化代码，你敲的 `conda activate` 只是调用了 `conda.exe`，它无法修改当前会话的环境变量——所以不报错、不切换、提示符没有变化。

### 1.3 常用设置

```powershell
conda config --set auto_activate_base false   # 已执行: 新窗口不再自动进 (base)
conda activate floraqwen                       # 进入项目环境
conda deactivate                               # 退出环境
```

**你已关闭 `auto_activate_base`，所以现在每次开新窗口的正确姿势：**

```powershell
# 新窗口 = 无 conda 状态的"裸"环境 (此时 python 是系统里的 D:\Python, 不能直接用!)
conda activate floraqwen          # ① 先激活 (提示符前出现 (floraqwen))
cd F:\GithubDeskClone\FloraQwen   # ② 再进项目目录
python scripts\check_env.py       # ③ 正常跑 (已激活, python 就是环境里的)
```

> 想更省事：**启动器 `run.ps1` 不需要激活**——新窗口里直接 `cd F:\GithubDeskClone\FloraQwen` 后 `.\scripts\run.ps1 scripts\xxx.py` 即可（它自动调用 floraqwen 的 python + 全部环境变量）。只有手动敲 `python xxx.py` 时才必须先 `conda activate floraqwen`。

**激活是否成功的唯一判断标准**（提示符前缀不算数）：

```powershell
python -c "import sys; print(sys.prefix)"
# 必须输出: D:\DataMining\Anaconda3\envs\floraqwen  ✅
# 如果输出:  D:\Python                                ❌ 没激活（D:\Python 是系统里另一个 Python，别用它）
```

## 5. 常见问题 FAQ

**Q1：又出现 "Downloading bytes" / C 盘开始变小？**
→ HF_HOME 没设置，huggingface 正在往 C 盘默认缓存 `C:\Users\ASUS\.cache\huggingface` 重新下载 8.9GB。处理：
1. 在运行的窗口按 `Ctrl+C` 停止；
2. 删除误建缓存（可选）：`Remove-Item C:\Users\ASUS\.cache\huggingface -Recurse -Force`；
3. 改用启动器（方式 A）或先 `. .\scripts\set_env.ps1` 再跑。
模型明明在 F 盘却"没用上"，就是因为 HF_HOME 没指向它。

**Q2：提示符前面多了 `(base)`？**
→ 正常，conda 默认自动激活 base。不想要就 `conda config --set auto_activate_base false` 后重开窗口。

**Q3：`python` 不是 floraqwen 的？**
→ 用 `python -c "import sys; print(sys.prefix)"` 检查。输出 `D:\Python` 说明 PATH 里系统 Python 抢了先——要么先 `conda activate floraqwen`，要么一律用启动器 / 全路径 `D:\DataMining\Anaconda3\envs\floraqwen\python.exe`。

**Q4：`can't open file '...\scripts\xxx.py'`？**
→ 当前目录不对。先 `cd F:\GithubDeskClone\FloraQwen`（脚本路径相对项目根目录）；启动器方式无此问题（自动切到项目根目录）。

**Q5：模型加载很久 / 显存报错？**
→ 首次加载 8.9GB 权重并做 4-bit 量化，2~5 分钟正常；4-bit 推理显存约 4~5GB，8GB 显卡没问题。可先 `nvidia-smi` 确认没有其他程序占显存。

**Q6：加载到 ~30% 就闪退（无任何报错，事件日志显示 torch_cpu.dll 0xc0000005）？**
→ 这是 transformers 5.5.0 在 Windows 上的已知坑：**4-bit 量化加载时不能传 `dtype=torch.bfloat16`**，否则在 ~30% 处原生崩溃（访问冲突）。`infer.py` / `train_lora_trl.py` 已于 2026-08-18 修复（去掉该参数），直接重跑即可。若自己写加载代码，记住：`from_pretrained(..., quantization_config=BitsAndBytesConfig(load_in_4bit=True))` 时**不要传 dtype/torch_dtype**。

**Q7：识别结果带 emoji 时打印报错 `'gbk' codec can't encode ...`？**
→ Windows 控制台默认 GBK 编码。`infer.py` 已内置 UTF-8 输出修复；若自己写脚本，在开头加 `sys.stdout.reconfigure(encoding="utf-8")`。

**Q8：C 盘又少了好几 GB？看看是不是 pagefile.sys 膨胀了**
→ 根因：加载 8.9GB 模型时若可用内存不足（本机 16GB 内存常被 Edge/VS Code/QQ/微信占掉大半），Windows 会疯狂换页并把**页面文件 pagefile.sys 自动涨大（本机曾涨到 21GB+），且不会自动缩回**。排查：`Get-Item C:\pagefile.sys` 看大小。解决（管理员 PowerShell）：
```powershell
wmic computersystem set AutomaticManagedPagefile=False
wmic pagefileset where name="C:\\pagefile.sys" set InitialSize=8192,MaximumSize=8192
# 重启后生效, pagefile 缩到 8GB, C 盘立刻多出 ~13GB
```
（或：系统属性 → 高级 → 性能设置 → 高级 → 虚拟内存 → 自定义大小 8192~8192。）预防：跑模型前关掉 Edge/QQ/微信等大内存程序；pagefile 也可整体搬到 F 盘。另外 `powercfg /h off`（管理员）可删休眠文件 hiberfil.sys 再省 6.25GB（代价：失去休眠/快速启动）。

**Q6：想重新/换模型下载？**
→ 用 ModelScope（国内最快，已实测 18 分钟下完 8.9GB）：
```powershell
modelscope download --model Qwen/Qwen3-VL-4B-Instruct --local_dir F:\hf-cache\models\Qwen3-VL-4B-Instruct
python logs\wire_hf_cache.py    # 校验并接入 HF 缓存
```
或 Ollama（M6 部署用）：`ollama pull qwen3-vl:4b`。

**Q7：安装新依赖？**
→ 必须装进 floraqwen 环境（别装到 base 或 D:\Python）：
```powershell
conda activate floraqwen
pip install xxx -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 6. 环境变量说明（`scripts\set_env.ps1` 与 `scripts\run.ps1` 自动设置）

| 变量 | 值 | 作用 |
|---|---|---|
| `HF_HOME` | `F:\hf-cache\huggingface` | HF 模型缓存指向 F 盘（**防止写满 C 盘**） |
| `HF_ENDPOINT` | `https://hf-mirror.com` | 国内镜像（万一需要联网拉取小文件） |
| `HF_HUB_DISABLE_XET` | `1` | 禁用 Xet 协议（否则 401） |
| `HF_HUB_OFFLINE` | `1` | 纯离线加载（模型已缓存完整，避免任何联网） |
| `MODELSCOPE_CACHE` | `F:\hf-cache\modelscope_cache` | ModelScope 缓存也放 F 盘 |
